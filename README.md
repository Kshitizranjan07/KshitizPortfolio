# Kshitiz Ranjan — Portfolio

> **Live site:** [kshitiz-portfolio.vercel.app](https://kshitiz-portfolio.vercel.app) *(updates after Vercel connects)*

A minimal dark UI/UX designer portfolio for **Kshitiz Ranjan**, undergrad designer at Manipal University Jaipur.

## Stack
- Pure **HTML + CSS + Vanilla JS** — zero dependencies, zero build step
- Animated starfield canvas, scroll-reveal, tools ticker, bento grid

## Projects Featured
1. **Stylus** — Design System
2. **Health Care 6D** — Healthcare UI
3. **Design Audit** — Heuristic Evaluation (Craigslist)
4. **Content Delivery IA** — Information Architecture

## Deployment
Deployed on **Vercel** via GitHub auto-deploy. Every push to `main` triggers a new deployment.

## Local Preview
Just open `index.html` in any browser — no server needed.
